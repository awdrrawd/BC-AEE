# 設定與資料儲存原則

[文件索引](../README.md) · [互動架構圖](https://awdrrawd.github.io/BC-AEE/docs/architecture/index.html)

## 本地共用偏好

`src/core/settings.ts` 使用 `localStorage` 的 `liko-aee-settings`，同一瀏覽器設定檔、同一網站來源內的帳戶共用。

- 功能開關、語言、主題、外框顏色、面板位置與布局。
- 預覽角色、服裝懸停試穿、道具懸停試穿的快捷開關。
- 視角、背景、格線、拾取模式與衣櫃操作偏好。
- 自由繪圖與物品字型的本機偏好；需要其他玩家知道的部分另行發布。

快捷開關直接讀寫 `settings`，不再使用 `ExtensionSettings.AEE` 或 runtime 副本。既有本地 `characterPreviewActive` 保留；兩個試穿快捷開關在本地尚無紀錄時預設關閉。舊帳戶線上值不再讀寫，也不主動刪除，避免舊版本與新版本混用時破壞資料。

## 帳戶資料與衣櫃內容

這些是使用者內容或身分資料，不是環境偏好，不應自動讓多帳戶共用。

| 資料 | 儲存位置與範圍 |
| --- | --- |
| BC 原生線上衣櫃 | 遊戲帳戶原生資料 |
| 擴充線上衣櫃 | `ExtensionSettings.FBCWardrobe`，帳戶專屬 |
| SPS 衣櫃 | SPS 線上服務，使用帳戶身分存取 |
| 本地衣櫃 | IndexedDB，預設依帳號隔離；由「跨帳戶共用」偏好決定是否共用 |
| 自訂衣櫃背景 | 本地 IndexedDB |
| WCE 圖層覆蓋資料 | `ExtensionSettings.WCEOverrides`，維持互通格式 |
| Studio OAuth 身分 | `ExtensionSettings.StudioOAuth`，帳戶專屬，不公開分享 |

衣櫃舊分類、欄位中繼資料與遷移旗標仍由既有遷移流程管理，不因快捷開關調整而搬動。

## 對其他玩家發布的狀態

`OnlineSharedSettings.AEE` 只發布版本、`ItemFont`、`FreeDraw`。它是本機偏好的對外副本，不反向覆蓋本地設定。

判定對方是否正在啟用 AEE 必須先通過即時狀態握手，不能只因線上資料仍存在就認定啟用；確認在線後才讀取分享的能力設定。

## 不持久化的執行狀態

拖曳狀態、懸停目標、試穿備份、畫布快取、同伴握手與有效期限留在記憶體。它們描述當下操作，不能當成下次登入的偏好恢復。

## 設定記憶與初始化

`SettingsStore` 在模組初始化時讀取本地資料，`Setting.get()` 讀取記憶體中的設定值；缺少欄位時使用該設定的預設值。

- 操作偏好透過 `Setting.set()` 或 `BooleanSetting.toggle()` 更新，預設同時寫回本地並通知訂閱者。
- `set(value, false)` 只修改當前記憶體值，不立即寫入本地；但後續其他設定儲存時會序列化整份設定，因此不能用它承載必須永遠不落盤的暫存資料。
- 真正的臨時狀態放在 `runtime`、元件 state/ref 或所屬控制器內，不建立第二份持久化設定副本。
- 本地偏好不依帳戶重新載入，也不以舊的 `ExtensionSettings.AEE` 值覆蓋；切換帳戶不應要求使用者重開設定開關。
- 目前沒有跨分頁的 `storage` 事件同步；已開啟的其他分頁不會即時套用變更，重新載入後才會讀取已保存值。
- 本地讀取失敗或 JSON 無效時使用預設值；寫入失敗時當前操作仍可生效，但不能保證重新載入後保留。

## 記憶體生命週期與清理

以下區分既有實作與後續維護原則，不能把「離開畫面」視為整個插件已卸載。

| 狀態 | 現有管理位置與生命週期 |
| --- | --- |
| 懸停高亮、臨時試穿 | `appearanceHooks.ts` 依畫面／階段轉換呼叫停止函數；`uiController.ts` 負責還原與清除試穿狀態 |
| 拖曳與手勢 | `dragController.ts` 與 `editorToolState.ts` 管理當前操作，不寫入持久化設定 |
| BC 角色預覽快取 | `AppearancePreviewBuild` 重建，`AppearancePreviewCleanup` hook 處理清理；預覽開關與快取內容分開管理 |
| AEE 同伴狀態 | `aeePresence.ts` 管理握手 Map；狀態有效期 75 秒，過期即不視為啟用，離房／同步流程清理紀錄 |
| IndexedDB 連線 Promise | `indexedDb.ts` 重用開啟結果，開啟失敗時清空 Promise，讓後續操作可重試；連線快取不是衣櫃內容本身 |

新增或調整功能時應遵守：

1. 由建立資源的模組提供停止／清理入口，優先接入既有畫面轉換或元件卸載流程，避免為同一狀態增加多個初始化 hook。
2. 結束操作時停止相關 timer、動畫影格、監聽器或訂閱，釋放不再使用的角色、物品與畫布參照；臨時外觀修改應先還原再丟棄備份。
3. Map／快取須有明確的有效範圍、失效條件或容量限制。與帳戶相關的非同步結果必須確認仍屬於當前帳戶，才能套用。
4. 清理可重複呼叫，不能因清理尚未開始的操作而出錯；清除執行狀態不能順便重設使用者偏好。
5. 驗證首次載入、重新載入、同環境切換帳戶、離開後重進畫面，以及功能關閉後重新開啟。預覽停用必須有明確結果，不能回退到另一份設定而重新啟用。
